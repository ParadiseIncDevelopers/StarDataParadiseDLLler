# Pinned Server protocol

`sdp-contract-v1.zip` is the Server's reproducible v1 artifact from `contracts/v1`, including the public wire specification, fixtures and internal C++ wire codec.

SHA-256 `e6500900a3fa34910781ea92d5e41fe8716511fac6f6d6c689ff9cce15d578ab`

The build verifies the pin before extraction. Updating the protocol artifact requires a deliberate version or compatible revision change and a matching SHA-256 update. The archive supports independent builds of the native client without a checkout of the Server.
